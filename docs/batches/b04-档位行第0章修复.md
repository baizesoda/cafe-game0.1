#### 2.6 关键决策

- **D21 严格规范式解析**（`/^chapter-(\d+)$/` + 正整数）：旧 `\D` 剥离会把 `1.5` 读成 `15`、`-1` 读成 `1`——制造另一个假章号；严格式让「读得出 / 读不出」的边界可断言。被否：沿用 `\D` + `|| 0`；只判空串。
